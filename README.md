# bash-scripts

My first bash scripts while learning Linux and cybersecurity.

## Scripts

### backup.sh
Copies a folder into `backups/` with today's date in the name.

Usage: `./backup.sh docs`

### search.sh
Counts how many times a word appears in a file (useful for checking logs).

Usage: `./search.sh failed test.log`

### ping.sh
Checks if a host is alive.

Usage: `./ping.sh 8.8.8.8`

## How to run
Make a script executable before running it:

`chmod +x script.sh`
